# AI Use Declaration

This project was developed with support from AI tools for planning, code generation, validation, and documentation review. The final output was checked and adjusted to ensure it matches the AT3 requirements and follows the assignment specifications.

The use of AI included:
- helping structure the OOP design;
- generating code for classes, repositories, and workflow logic;
- drafting documentation and testing coverage;
- reviewing validation and persistence logic.

No confidential or real institutional data was used in the project.
